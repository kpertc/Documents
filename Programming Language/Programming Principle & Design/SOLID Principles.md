
### 1.  Single Responsibility
	- One reason to change / one actor it answers to
### 2.  Open-closed
	- Open for extension
	- Close for modification
### 3.  Liskov substitution
	- Subtype can replace its base type without breaking the caller
### 4.  Interface segregation
	- Many small interfaces, don't force a client to depend on members it doesn't use
### 5.  Dependency inversion
	- Depend on abstractions, not on concrete implementations
