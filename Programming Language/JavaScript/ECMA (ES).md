#JavaScript 

> Ecma International (formerly the European Computer Manufacturers Association) is an international non-profit standard organization, publishes ECMA-262, the ECMAScript specification.

ECMAScript (ES)
- JavaScript
- JScript
- ActionScript

<br>

- ES5 -> 2009
- ES6 -> 2015 (fix & more features)
ES6 and ES2015 <ins>are the same thing</ins>
Backward Compatibility, ES5 code still runs on ES6+ engines (the spec almost never removes features). The reverse is not true, hence Babel.

<br>

### New in ES6

- `let` and `const`  let -> limited scope
- Classes and Inheritance
- Arrow Function
- Template Strings
- Promises & Asynchronous Data
- Modules `import` / `export`
- Destructuring, Spread / Rest
- `Map` / `Set`

### After ES6 (one feature per year)

- ES2016 - `**`, `Array.includes`
- ES2017 - `async` / `await`
- ES2018 - object spread, `Promise.finally`
- ES2019 - `Array.flat`, `Object.fromEntries`
- ES2020 - optional chaining `?.`, `??`, `BigInt`
- ES2021 - `String.replaceAll`, `??=`
- ES2022 - top-level `await`, class private `#field`, `Array.at`
- ES2023 - `toSorted` / `toReversed` (non-mutating array methods)
- ES2024 - `Object.groupBy`, `Promise.withResolvers`
- ES2025 - `Set` methods (`union` / `intersection`), iterator helpers
