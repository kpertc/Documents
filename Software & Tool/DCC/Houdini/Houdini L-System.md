`F` Forward
`f` Forward no geometry

`+` Right
`-` Left

`!` Thickness Scale
`"` Step Size Scale

`~` Random amount (Pitch / Roll / Turn)

`:` Probability

`&` Pitch Down
`^` Pitch Up

`\\` Roll CW
`/` Roll CCW

`[]` Branch
`()` Explicit value
